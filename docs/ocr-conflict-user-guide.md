# 识别结果与原图冲突时，怎样继续整理

可以直接对Agent说：

> 先对照原图核对这道题的题干、作答和批改。列出明确看见的内容与识别冲突；有依据的部分继续整理，看不清的具体位置留待确认。保留各份识别结果，不因识别漏字判我漏答。

## 核对时看什么

| 情况 | 应当怎样处理 |
| --- | --- |
| 图上有字，识别结果没有 | 回看该位置，记录原图所见；不能直接判定未作答 |
| 同一图两次识别不同 | 并列原文与原图依据；新结果、付费结果或多数结果不自动胜出 |
| 描述说有某条线或某个关系 | 在原图定位并核对；流畅的描述不是题目给定条件 |
| 某处仍看不清 | 指明具体字符或区域，请用户核对该处；其余有依据的部分可以保留 |
| 原作答数学上有错 | 忠实保留原式，再分别写判断和建议，不把订正混入转录 |
| 只有OCR出了错，学生实际作答正确 | 保留正确判断及证据，不为凑错题而生成错因或补救练习 |

## 已遇到的几何例子

原图（本地历史证据未公开）要求在两圆除B以外的另一交点标E；学生图上方交点附近可见红色E。整页OCR列出E但描述了错误几何关系，后续裁图的文字提取片段又仅剩A。两种识别都不能单凭文字证明学生未答，也不能把错误描述加入题干。

这道公开诊断题保留“Agent依据原图判断正确、卷面未见批改、待人工复核”。所选任务仅为标E的小题；照片中顺带出现的另一小题不自动纳入漏答判断。红色也不能单独证明是谁写的。

核对时可以说：

> 请把原图、识别原文和你的判断分开列出，并标出判断引用的位置。暂时不要把这道题正式纳入错题集，也不要生成练习。

实际人工核对后，再明确说应纳入、排除或仍不确定。没有这一步，Agent不会把自己的核图结论写成人工确认。需要复练时，使用已核对的题面；含原答案或批改的图片不能直接当作独立练习题面。
