## 复现

```sh
uv sync --locked --python 3.12
uv run pytest -q
uv run ruff check src tests scripts
uv run python scripts/configure_local.py
uv run python scripts/smoke_mcp.py
uv run python scripts/build_release.py
```

解压生成的 ZIP，在其中执行 `python3 install_release.py --target <新的安装目录>`。不要覆盖正在使用的运行环境。安装器运行隔离的合成材料验证，不调用 OCR。重新运行的结果应独立记录，不能沿用本文件的测试数量。

原始材料、响应、安装清单与私有诊断报告留在本地，不随代码公开；读者应使用自行授权的材料验证效果。
