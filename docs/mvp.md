# 参赛 MVP：安装与演示

适用：macOS、本地 stdio MCP、具备看图能力的 Agent 宿主。用户只需三个入口：整理作业、开始重练、导出材料。首次建议选1–3页代数作业中的一题。

## 本地安装

1. 解压本地发布 ZIP，进入解压目录。
2. 执行 `python3 install_release.py --target /你选择的全新目录/study-errorbook`。需要已安装的 uv；首次可能下载 Python 3.12 与固定版本依赖。包内不含完整离线依赖。
3. 看到 installation.json 后，将目标目录的 `plugin/` 作为本地 Codex 插件源注册，或把 `mcp.json` 导入支持本地 stdio 的宿主。安装器不修改全局配置；本轮仅验证隔离子进程，没有切换当前连接。
4. 检查 workspace_status.runtime_version 与 installation.json 相同，再说“整理作业，先做第1题”。真实OCR需配置自己的TextIn凭据、确认材料上传和页数预算；已有缓存优先续接。

完整安装、配置、升级回退参见 [安装说明](distribution.md)。本轮35个底层工具由Skill编排，用户无需逐个选择。manifest、Skill和非editable运行时一同打包。

## 三个入口

**整理作业**：导入 → 必要脱敏 → 已有缓存或明确授权的识别 → 整页与局部核图 → 题号清点 → 可观察错因与变式 → 适用验算/用户复核。题号清点需整页证据；同页不同题号不能复用同一记录，跨页续题可在不同页关联同一记录。旧清点如有同页重复关联，将保持待定并要求更正；未整理题明确待定或附理由跳过。已处理仅表示用户已纳入/排除，不代表掌握或整卷自动批改。

**开始重练**：只展示中性题面。收到真实作答后记录是否独立、用了提示或看了解析，再保存反馈。一次答对不代表掌握。

**导出材料**：给学生 `practice-only.zip`，完整解压后打开 practice.html；`answers.html` 独立保管。完整导出目录含答案、原卷作答和反馈，不能整目录发给学生。有作答时 feedback.html 展示每题最近20次记录与最新反馈，完整历史仍在本地。页面离线可用、适配窄屏、支持浏览器打印；没有自动生成PDF。

## 跨会话和错误恢复

- list_documents → read_task_progress 找回材料与下一步，list_parse_jobs 找既有任务，避免新上传。
- HTTP429和40306均暂停查询；处理限流后由用户明确要求，携当前版本 resume_job_observation，仅查询原任务。
- 完成异步任务的缓存丢失时，显式 recover_parse_result 仅GET查询和重取原结果，不创建任务。不适用于无远端任务ID的同步识别；结果过期时保留状态并提示可信备份/原图人工核对。
- 擦除失败/提交未知默认返回旧尝试。用户明确同意可能重复计费后才能带当前expected_attempt显式重提，保留历史与回执。不会自动重发未知付费请求。

## 可复现离线演示

在开发环境运行：

```sh
uv run python scripts/demo_mvp.py --output /tmp/study-errorbook-demo-new
```

输出目录须不存在。脚本创建两页合成代数作业、局部遮盖、标注为合成的识别缓存、证据、错因、方程变式验算、模拟复核、独立作答与反馈，导出学生ZIP和答案册并重新打开工作区验证续接。不使用真实卷、不调用任何网络API；模拟复核不代表真实用户意见，合成缓存不代表真实OCR质量。
